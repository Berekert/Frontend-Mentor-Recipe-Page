# Simple Omelette Recipe

A responsive recipe page for a simple omelette. The page presents the recipe introduction, preparation time, ingredients, step-by-step instructions, and nutritional information in a clear, readable layout.

## Features

- Responsive recipe layout for mobile and desktop screens
- Omelette image with descriptive alternative text
- Preparation time summary
- Ingredients and numbered cooking instructions
- Nutrition table showing values per serving
- Custom typography using Young Serif and Outfit

## Built With

- Semantic HTML5
- CSS3
- Google Fonts

## Getting Started

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.

The page loads its stylesheet and recipe image from the local project files.
